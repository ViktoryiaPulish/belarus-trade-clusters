# Выявление групп стран со схожей структурой торговли с Республикой Беларусь

Кластеризация стран по долям товарных групп в общем объёме торговли с Беларусью.  
Применён метод K-means (k = 4), выполнена интерпретация профилей кластеров, построены тепловые карты, проекция PCA и интерактивная географическая карта.

## Что внутри

Анализ состоит из 4 блоков: **Подготовка данных**, **Кластеризация**, **Анализ профилей**, **Визуализация**. В каждом блоке — расчёты, графики и текстовые выводы.

## Данные

- **Источник торговли:** `trade_long.csv` (сформирован в задании 1, содержит торговые потоки, разбитые по группам товаров).
- **Товарные группы:** 8 категорий — деревообработка и мебель, машины и оборудование, металлы и металлоизделия, продовольствие и сырьё для АПК, транспорт, фармацевтика, химия и полимеры, электроника и ИКТ.
- **Страны:** 28 стран (СНГ, ЕС, Дальнее зарубежье).
- **Единицы:** доли товарных групп в общем объёме торговли (сумма по строке = 1).

## Структура репозитория

- `data/` — исходные данные 
- `output/` — результаты: графики `.png`, таблицы `.csv`, интерактивная карта `map_clusters.html`
- `belarus_trade_clusters.py` — основной скрипт
- `Задание 3.pdf` — текстовый отчёт с методологией, таблицами, графиками и выводами
